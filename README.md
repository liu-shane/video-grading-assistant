# 🎬 影片評分小幫手 (Video Grading Assistant)

**影片評分小幫手** 是一個專為課程作業、專題競賽與影音作品評量打造的網頁平台。支援教師或評審上傳「影片製作內容說明」與「評分標準 Rubrics」，並可透過單一影片、影片網址或 Excel 清單進行批次評分，最後一鍵匯出包含**各分項得分、總分與綜合評語**的 Excel (`.xlsx`) 報表。

---

## ✨ 四大核心功能

1. **📄 功能一：上傳影片製作內容說明**
   - 支援上傳 **圖檔 (`.jpg`, `.png`, `.webp`)**、**Word 檔 (`.docx`)** 或 **PDF 檔 (`.pdf`)**。
   - 內建自動文字解析（Mammoth.js / PDF.js）與圖檔預覽，亦可連結 Gemini 視覺模型進行 OCR 辨識或手動編輯規範重點。
   - 預設載入「設計你的人生：期中報告 — 你眼中的自己 (90~120秒)」製作說明。

2. **📊 功能二：上傳影片評分 Rubrics**
   - 支援上傳 **圖檔 (`.png`, `.jpg`)**、**Word 檔 (`.docx`)** 或 **PDF 檔 (`.pdf`)**。
   - 提供結構化評量指標與配分編輯器，可自由新增、修改或調整各項指標名稱、配分權重及四個等級（優秀 / 良好 / 基礎 / 待加強）之評量標準。
   - 預設內建「設計思考期中影片評分 Rubrics」5 大指標（共 100 分）：
     - 成長故事與自我探索 (25 分)
     - 他人觀點與訪談 (20 分)
     - 自我覺察與反思 (25 分)
     - 故事結構與創意 (20 分)
     - 技術品質與規範 (10 分)

3. **🎥 功能三：提供影片或網址清單（單一 / 批次 Excel）**
   - **方式 A（單一影片網址）**：支援輸入序號、YouTube / 雲端影片網址與作品觀察備註。
   - **方式 B（上傳影片檔案）**：支援上傳本機 `.mp4`, `.webm`, `.mov` 等影片，系統會自動偵測影片片長（檢核是否符合 90~120 秒規範）與解析度，並擷取關鍵畫面。
   - **方式 C（上傳 Excel 批次清單）**：支援上傳含有「**序號**」及「**網址**」欄位的 Excel 檔案（`.xlsx`, `.xls`, `.csv`），亦提供標準範本檔下載。

4. **🏆 功能四：評分結果與 Excel 報表下載**
   - 依據上傳之 Rubrics 進行逐項評分，完整呈現**每一項評分指標的得分、分項評定說明、總分與綜合評語**。
   - 支援點擊任一作品開啟「詳細檢視與微調視窗」，可即時觀看影片並微調各分項給分與評語。
   - 點擊「**下載評分結果 Excel (.xlsx)**」即可匯出包含「影片評分結果總表」與「評分標準 Rubrics 備查表」的雙工作表 Excel 檔案。

---

## 🚀 線上使用與本機執行

- **GitHub Pages 線上版**：直接透過瀏覽器開啟 GitHub Pages 網址即可使用所有功能。
- **本機直接執行**：下載專案後直接以瀏覽器開啟 `index.html`，或使用任意靜態伺服器（如 `npx serve` 或 `python -m http.server 8000`）啟動。
